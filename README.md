# Devin Prater's Apps

An [AltStore](https://altstore.io/) (and SideStore) source with two apps,
each its own listing:

- **iBestSpeech** — Keynote Gold voices as system voices.
- **iTruVoice** — TruVoice voices as system voices.

## Add it

On your iPhone, open this link (or paste the URL into AltStore → Sources → +):

[Add to AltStore](https://apps.apple.com/app/altstore/id1506645217)
`https://raw.githubusercontent.com/devinprater/apps/main/apps.json`

Then open the source and install either app. Keep AltStore refreshed so the
installs stay valid.

## How it stays current

`apps.json` is generated by `update_source.py` from the latest GitHub
release of each app repo (sideload `.ipa` only). A scheduled workflow
regenerates it daily and on demand — old versions stay listed, new ones go
on top. App icons live in `icons/`.
